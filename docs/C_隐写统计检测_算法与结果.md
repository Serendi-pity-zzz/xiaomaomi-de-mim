## 1. 任务边界与判定口径

- 本模块做**统计检测**：判断图像（或约定区域）的 LSB 值对分布是否呈现 LSB 替换
  留下的均衡化特征。它不解码、不需要密钥，也不把“能否提取”当成检测结论。
- 检测结果只有 `suspicious` / `clean` / `inconclusive` 三种。`clean` 的含义是
  **未发现统计证据**，不是“证明未嵌入”；`suspicious` 是**证据**，不是“含密概率”。
- `score` 是 0–1 的检测分数（越高越可疑），不是后验概率，也不是严格假设检验的
  p 值。阈值来自校准文件，而不是凭经验直接写死。
- 统计检测与 D 的完整性校验、B/G 的提取是不同功能，不能互相替代。

## 2. 算法

### 2.1 值对效应

对区域内全部 RGB 通道样本做 256 级直方图，把相邻灰度值 `(2i, 2i+1)` 看作一个
**值对**。LSB 替换只会在值对内部把样本从偶数搬到奇数或相反，因此每个值对的总数
基本不变，而偶/奇的相对比例会被推向接近相等（Westfeld 型卡方攻击的观察基础）。

### 2.2 经典卡方统计量

记值对 i 的偶、奇数计数为 `a_i, c_i`，`n_i = a_i + c_i`，只统计 `n_i > 0` 的值对，
值对数为 `k`：

```
r = Σ_i (a_i - c_i)² / (2 n_i)
```

这是常见卡方攻击实现采用的写法（每个值对只累计一项，等于 Pearson 统计量的一半）。
未嵌入时 `a_i` 与 `c_i` 往往相差很大，`r` 很大；完全 LSB 替换且载荷比特近似随机时
`r` 会降到 `k` 的量级。

### 2.3 载荷比特偏置修正

文本载荷的 0/1 比例通常不是 0.5（ASCII 高位恒为 0、UTF-8 中文有固定前缀位），
直接用上式会把全容量嵌入误判为“干净”。设区域内 LSB 为 1 的比例为 `b`（奇数样本
数 / 总样本数），`b_i = c_i/n_i`，可以严格分解：

```
r = 2N(b - 0.5)² + 2 Σ_i n_i (b - b_i)²      （N 为总样本数）
```

第二项衡量“各值对的奇偶比例是否都等于全局比例 b”，与载荷整体偏置无关。本模块用

```
r_adj = max(0, r - 2N(b - 0.5)²)
```

作为检测统计量。全部样本的 LSB 都接近同一个常数时（`b≈0` 或 `b≈1`）修正项会
吞掉全部信号，此时模块返回 `inconclusive`，不强行给出结论。

### 2.4 分数与阈值

```
score = P(χ²_{k-1} ≥ r_adj)
```

`score` 越大越可疑。这里沿用经典卡方攻击的惯例（自由度 `k-1`），因此它**不是**
严格 p 值：在完全均衡且 `b≈0.5` 的含密区域，`r_adj` 约为 `χ²_k/2`（即 `k/2`
量级），`score` 集中在接近 1 的区间；未嵌入时 `r_adj` 远大于 `k`，`score≈0`。
分数只是单调证据，阈值由实测校准：

- 校准集（与评估集不同文本、不同种子）中结构化覆盖样本最大分数为 `0.000046`；
- “位置无关载荷”（keyed/ASCII）全容量含密样本最小分数为 `0.593774`；
- 可用阈值区间 `[0.05, 0.59]`，取可解释的 **0.5**。

阈值与全部校准样本记录在 `core/steganalysis_calibration.json`。文件带
`calibration_id = sha256(除 id 外的规范 JSON)`；被改动而未重新生成时
`load_calibration()` 会拒绝加载。

### 2.5 RS 辅助特征

实现了 Fridrich 型 RS 分组翻转：组大小 4，掩码 `(0,1,1,0)` 及其相反数，按行优先、
逐通道分组，`f(G)=Σ|x_{i+1}-x_i|`；比较翻转前后的 regular/singular 组数，输出
`R/S` 比例与 `d = R - S`。

实现中的负翻转在 0/255 处保持原值，属于边界保护的辅助实现；不按经典 RS 嵌入率模型解释。
不足 4 像素时没有完整分组，计数为 0，比例为 null，不能将缺失特征解释为零风险。

**RS 不参与判定。** 本项目载体的平坦色块和二维码 0/255 饱和值破坏 RS 的模型假设；
实测中 `d_m` 随载荷单调下降（见 5.5），可作为辅助证据，但固定阈值会把噪声类载体
误判，且本项目没有实现经过独立验证的 RS 嵌入率估计，因此不报告“估计嵌入率”。

## 3. 实现与接口

### 3.1 签名

```python
from core.steganalysis import analyze, rs_features

result = analyze(
    image,                 # PIL.Image，任意模式，内部转 RGB
    region=(x, y, w, h),   # 左上原点，右下边界不包含；None 表示整图
    method='chi_square',   # 或 'rs'（只返回辅助特征，判定恒为 inconclusive）
    threshold=None,        # 覆盖校准阈值，用于实验对比
    calibration_path=None, # 默认 core/steganalysis_calibration.json
    include_rs=False,      # 在 details['rs'] 附带 RS 特征
)
```

返回的服务层字段（可直接 `json.dumps`）：

| 字段 | 含义 |
|---|---|
| `method` | `chi_square` / `rs` |
| `method_detail` | `chi_square_bias_adjusted` |
| `analysis_scope` | `region` / `whole_image` |
| `region` | `{x, y, width, height}` |
| `samples` | 参与统计的通道样本数 |
| `statistic` | `r_adj`；无法判定时为 `null` |
| `score` | 0–1 检测分数；无法判定时为 `null` |
| `threshold` / `threshold_source` | 阈值及来源（`calibration` / `manual`） |
| `decision` | `suspicious` / `clean` / `inconclusive` |
| `detail` | 中文解释，明确“分数不是概率” |
| `calibration_id` | 校准文件标识；手工阈值且无校准文件时为 `manual` |
| `limitations` | 固定局限列表，便于 UI 原样展示 |
| `details` | `classic_statistic`、`bias_correction`、`lsb_one_ratio`、`pair_count`、`degrees_of_freedom`、各值对计数、三通道分项、可选 `rs` |

`details.per_channel` 是三通道各自的统计量，仅作诊断，未做多重比较校正。

同一内置猫载体、同一区域的两个实测例子（载荷种子 11）：

| 输入 | `statistic`（`r_adj`） | `score` | `decision` | `pair_count` |
|---|---:|---:|---|---:|
| 未嵌入的 PNG | 35789.08 | 0.0 | clean | 10 |
| 顺序 ASCII 全容量 | 5.00 | 0.834 | suspicious | 10 |

### 3.2 区域与错误处理

- 区域必须是 4 个 `int`，`w/h > 0`，不越界；`bool` 不算整数。违规抛
  `ValueError`（中文原因），不返回假成功。
- 区域非空值对 `<2`、样本数 `<256`、或 LSB 全 0/全 1 时，返回
  `inconclusive` + `score=None`，不臆造分数。
- 整图分析可用，但会稀释信号（实测见 5.4），调用方应优先传载体元数据中的区域。
- 只对 RGB 值对统计；不做图像增强、缩放、JPEG 重存；PNG 无损是前提。

### 3.3 复杂度

区域统计是对像素的一遍直方图，160×200×3 样本在本机为毫秒级；整图 400 万像素
仍可接受。RS 是分组循环，整图会明显变慢，建议只对区域调用。

## 4. 实验设计

### 4.1 数据与分离

**没有使用真实猫图/自然照片**（E 的数据集尚未交付），全部载体由程序生成：

- `builtin_cat_qr`：项目内置猫咪 + 二维码（`core/baseline.generate`），区域取
  CAT1 的 `(width-180, 32, 160, 200)`。公开文本长度不同会改变二维码版本/图像尺寸，
  但区域内猫咪绘制相同，因此这不是 12 张独立载体，样本文本多样性有限。
- `synthetic_*`：gradient / plasma / noise / flat / checker / radial / stripes，
  260×256，确定性种子。**合成载体不代表自然照片分布**，只用于可控对照。
- 校准集与评估集使用不同公开文本（`calibration` vs `evaluation` 前缀）、不同
  合成种子（100/101 vs 300/301）和不同载荷种子。校准用 20 个结构化覆盖样本、
  40 个含密样本（其中 12 个顺序中文全容量为**已知漏报**，不参与阈值计算）。
- 评估用 26 个覆盖样本（12 内置 + 14 合成）、456 条含密记录（26 个载体 × 17 个
  条件，另加 14 个合成载体的 keyed 全容量条件），以及 10 个“LSB 已随机”对照
  与 4 个 PNG 重存检查。

### 4.2 载荷与参数

- 容量 `11960` 字节（CAT1 净载荷）；载荷长度 `64 / 1024 / 4096 / 8192 / 10240 /
  11960`，即约 0.5%–100% 容量。
- 顺序嵌入（空 key）与密钥置乱（非空 key）分别测试；消息分 ASCII 与中文 UTF-8。
- 全容量条件使用 3 个载荷种子（11/12/13、21/22/23）检验消息内容敏感性。
- 密钥值不写入 CSV、日志或本文；CSV 只记录 `lsb-keyed` 标签。

## 5. 结果（2026-11-15 实测）

2026-11-15 的结果叙述保留于本节；2026-11-17 复测的原始逐条记录、RS 记录及汇总
保存在 `docs/C_results/`，可随仓库交付。评估脚本默认仍输出到被 Git 忽略的
`outputs/steganalysis/`；使用 `--output-dir docs/C_results` 更新交付快照。
汇总分别记录本次评估环境和原阈值的校准环境，避免将两次运行混为一谈。

本节不报告跨条件的单一“准确率”：检出率强烈依赖载荷大小、消息类型与载体结构，把它们
混成一个数会掩盖容量敏感性。下表按条件给出 TPR 与正常样本被标记为可疑的比例，
并附分子/分母；分条件准确率、误报率、漏报率及混淆矩阵由脚本自动输出到 `docs/C_results/summary.{json,md}`。
二分类指标只在已判定样本上计算，同时报告判定覆盖率；`inconclusive` 单列，不算阴性或正确。
表中的 TPR 使用全部含密样本作分母，因此存在未知时 `1−TPR` 是“未检出率”，并非已判定样本的漏报率。

|---|---:|---:|---:|---|
| 内置猫咪二维码 | 12 | 0 | 0 | 0.0% (0.0–24.3%) |
| 合成 gradient | 2 | 0 | 0 | 0.0% (0.0–65.8%) |
| 合成 plasma | 2 | 0 | 0 | 0.0% (0.0–65.8%) |
| 合成 noise | 2 | 0 | 0 | 0.0% (0.0–65.8%) |
| 合成 flat | 2 | 0 | 0 | 0.0% (0.0–65.8%) |
| 合成 checker | 2 | 0 | 1 | 0.0% (0.0–65.8%) |
| 合成 radial | 2 | 0 | 0 | 0.0% (0.0–65.8%) |
| 合成 stripes | 2 | 0 | 0 | 0.0% (0.0–65.8%) |

合计 26 个覆盖样本，0 个误报、1 个无法判定（全偶数值的 checker 载体触发
“偏置修正退化”保护）。样本量小，置信区间很宽，不能外推为通用 FPR。

### 5.2 含密样本（检出率）

内置猫咪二维码载体（12 张 × 3 个载荷种子）：

| 条件 | 载荷 | 样本数 | 检出 | TPR（95% CI） |
|---|---|---:|---:|---|
| 顺序 ASCII 全容量 | 11960 B | 36 | 36 | 100% (90.4–100%) |
| 置乱 ASCII 全容量 | 11960 B | 36 | 36 | 100% (90.4–100%) |
| 置乱中文 全容量 | 11960 B | 36 | 36 | 100% (90.4–100%) |
| 顺序中文 全容量 | 11960 B | 36 | 0 | 0% (0.0–9.6%) |
| 顺序 ASCII 64 B | 64 B | 12 | 0 | 0% (0.0–24.3%) |
| 顺序 ASCII 1 KB | 1024 B | 12 | 0 | 0% (0.0–24.3%) |
| 顺序 ASCII 4 KB | 4096 B | 12 | 0 | 0% (0.0–24.3%) |
| 顺序 ASCII 8 KB | 8192 B | 12 | 0 | 0% (0.0–24.3%) |
| 顺序 ASCII 10 KB | 10240 B | 12 | 0 | 0% (0.0–24.3%) |

结论：在本项目载体上，**只有接近全容量（约 100%）的嵌入能被可靠发现**；10 KB
（约 86% 容量）仍然全部漏报。中文顺序嵌入全容量也全部漏报（原因见 6.2），
而中文置乱嵌入可 100% 检出——说明该漏报来自“载荷比特与空间位置的相位相关性”，
不是中文本身不可检测。

> 注意：12 张内置猫图的检测区域像素相同（猫咪绘制固定），36 个全容量样本实际是
> 同一区域 × 3 个载荷种子的重复，不是 36 张独立载体；表中的 Wilson 区间按独立
> 样本计算，未做聚类校正，只用于粗略表达样本量，不能当作总体准确率区间。

把内置猫载体的覆盖样本（12 个，均判 clean）作为负类，可写出两个固定条件下的
混淆矩阵（同一组覆盖样本在两个矩阵中重复使用）：

| 条件 | TP | FN | FP | TN | TPR | FPR |
|---|---:|---:|---:|---:|---:|---:|
| 顺序 ASCII 全容量（11960 B） | 36 | 0 | 0 | 12 | 100% | 0% |
| 顺序 ASCII ≤ 10 KB | 0 | 60 | 0 | 12 | 0% | 0% |

这张表直观说明：阈值不是“准确率 100%”的通用检测器，而是只在全容量条件下有效；
10 KB 及以下全部漏报。中文顺序全容量属于 5.2 表中的已知漏报，不并入矩阵以免
掩盖失败案例。若强行计算 accuracy，全容量条件为 (36+12)/48 = 100%，≤10 KB
条件为 (0+12)/72 ≈ 16.7%；两个条件的正负样本比分别为 3:1 和 5:1，accuracy 会受样本配比影响，
因此报告以 TPR/FPR 为主，不把 accuracy 当作主要指标。

合成载体（keyed ASCII 全容量）：7 类各 2 个，全部检出（14/14）。顺序嵌入时
noise/flat/checker/radial 100% 检出，gradient/plasma/stripes 0%——说明该方法
并非对任意载体都有效，不能把“100%”写成通用准确率。

### 5.3 区域 vs 整图（全容量顺序 ASCII）

| 载体 | 范围 | 样本数 | 检出 | TPR |
|---|---|---:|---:|---|
| 内置猫咪二维码 | 约定区域 | 12 | 12 | 100% |
| 内置猫咪二维码 | 整图 | 12 | 0 | 0% |
| 合成载体 | 约定区域 | 14 | 8 | 57.1% |
| 合成载体 | 整图 | 14 | 2 | 14.3% |

区域选择是检测成败的关键：整图混入二维码的 0/255 与大量无关像素，值对均衡
证据被稀释。CAT1 的约定区域目前是 `(width-180, 32, 160, 200)`；区域一旦更换，
必须按新区域重新校准，不能沿用本阈值。

### 5.4 不可区分对照

把结构化载体的全部 LSB 随机化（不经过 CAT1 封装）后，10/10 被判为可疑。这类
图像与“全量 LSB 替换”在统计上本来就不可区分，因此不计入误报率；它说明本方法
的边界：对 LSB 已随机的载体（噪声图、部分截图、二次保存图），卡方无法区分
“天然随机”与“被嵌入”，任何阈值都会二选一。

### 5.5 RS 辅助特征（内置猫载体，顺序 ASCII）

| 载荷 | 样本数 | `d_m` 均值 | 最小 | 最大 |
|---:|---:|---:|---:|---:|
| 0（覆盖） | 6 | 0.976 | 0.976 | 0.976 |
| 4096 B | 6 | 0.639 | 0.639 | 0.639 |
| 8192 B | 6 | 0.296 | 0.296 | 0.296 |
| 10240 B | 6 | 0.127 | 0.127 | 0.127 |
| 11960 B | 6 | -0.016 | -0.016 | -0.016 |

`d_m` 随载荷单调下降，且在 4 KB（约 34% 容量）就明显偏离覆盖值，比卡方更早出现
信号；但 6 个样本来自同一区域内相同的猫咪绘制，不能当作 6 张独立图片的统计。
噪声类载体的 `d_m` 在覆盖时就接近 0，固定阈值不可迁移，因此只作为辅助特征输出，
不参与判定（见 2.5）。

### 5.6 PNG 重存

4/4 个全容量含密样本经 PNG 保存/重开后 `score` 完全相同，说明检测结果不受
Pillow PNG 编解码影响；这只是一致性检查，不是鲁棒性结论（F 负责干扰测试）。

## 6. 分析

### 6.1 为什么小载荷几乎检测不到

嵌入 64 B–10 KB 只改动了区域中约 0.5%–86% 的样本，未改动的平坦色块仍保留强烈的
值对偏斜；`r_adj` 只有在“几乎所有值对都被推向同一奇偶比例”时才会塌缩。实测
10 KB（约 86%）仍全部漏报。这是卡方攻击的容量敏感性问题，不是实现缺陷；要发现
小载荷，需要载体参考图、块级/局部检测或针对具体嵌入顺序的模型，且样本量要求更高。

### 6.2 为什么顺序中文全容量反而检测不到

中文 UTF-8 的比特模式有固定前缀位（如每字节最高位分布极不均匀）。顺序嵌入时，
“像素/通道位置 → 载荷比特位置”的映射是固定周期（3 通道与 8 比特的最小公倍
24），同一平坦色块的值对会系统性地只采到部分比特位置，导致各值对的 1 比例
`b_i` 相对全局 `b` 有稳定偏差；全局偏置修正只能去掉均值，去不掉这部分结构，
于是 `r_adj` 依然很大。置乱嵌入把位置随机化，`b_i≈b`，检测恢复到 100%。
这提示 B/G：若要评估抗检测性，位置置乱并不能隐藏全容量替换（反而利于统计检测），
而载荷随机化/加密同样会让卡方更有效——卡方针对的是“值对均衡”，不是“有无密钥”。

### 6.3 为什么部分合成载体漏报

gradient/plasma/stripes 的值分布覆盖大量灰度级、每对样本数少，且平滑结构与
顺序比特位置存在相关性；即使全容量嵌入，残余的按值对偏置依然显著，`r_adj` 不塌缩。
这再次说明阈值与检出率只对校准覆盖的载体类型有效，不能外推。

### 6.4 阈值能否直接用于真实照片

不能直接断言。自然照片的 LSB 分布、压缩历史、相机噪声与合成载体差异很大：
某些 PNG 截图/渲染图的 LSB 本身就近随机，会被判为可疑；某些强纹理照片在
小载荷下更难检测。E 交付合法猫图数据集后，应按“校准/评估分离”重跑
`tests/calibrate_steganalysis.py` 与 `tests/eval_steganalysis.py`，重新校准
阈值并更新 `calibration_id`；本文数字只对应 4.3 的环境与上述载体。

## 7. 局限（与模块 `LIMITATIONS` 一致）

1. `score` 是检测分数，不是含密概率或后验概率。
2. 只能发现值对均衡化；小载荷、位置置乱、自适应算法可能无证据。
3. 平坦/量化载体值对少（`k` 小），自由度低；极端 LSB 比例会触发 `inconclusive`。
4. LSB 已随机的载体与全量嵌入不可区分，可能“误报”，也可能无法给出结论。
5. 依赖约定区域；区域错误、裁剪、缩放都会破坏统计前提。
6. 仅 PNG 无损；JPEG、缩放、滤镜会改变值对统计。
7. 未实现/未宣称：RS 嵌入率估计、块级定位、SPA、真实照片准确率、跨版本校准。
8. 校准集样本量有限（20 覆盖 / 40 含密），置信区间宽；载体绘制重复度高。

## 11. 第 6 页答辩内容

单页文件：`docs/C_答辩页_统计检测_复核版.pptx`（16:9，白底、`#263358` 文字、`#4E477E`
强调色、`#EDF0FA` 浅蓝底，标题 32pt，微软雅黑），含讲稿备注；复核版已用 Artifact Tool
渲染检查，并通过结构、尺寸和原生图表/表格校验。若组长使用自己的模板，可直接复制以下六项：

- **一句目标：** 不解码秘密，只用 LSB 值对统计判断图像是否呈现 LSB 替换痕迹。
- **三步原理：**
  1. 值对效应：未嵌入时相邻灰度 `(2i, 2i+1)` 的偶/奇计数偏斜，LSB 替换把它们推向均衡；
  2. 偏置修正：`r = Σ(a−c)²/(2n)`，减去 `2N(b−0.5)²` 得 `r_adj`，避免文本 0/1 偏置造成漏报；
  3. 阈值校准：`score = P(χ²_{k−1} ≥ r_adj)`；覆盖最大 `0.000046`、可检测最小 `0.594` → 阈值 `0.5`。
- **关键实现：** `core/steganalysis.py`（Pillow + 标准库，无新增依赖）；阈值与样本写入
  校准 JSON，`sha256` 自校验；C 的 37 项测试中 36 通过、1 项可选 SciPy 验证跳过。
- **真实数据图：** 内置猫载体顺序 ASCII 检出率随载荷变化（横轴 64 B / 1 KB / 4 KB /
  8 KB / 10 KB / 11.96 KB，纵轴 TPR 0%–100%），配混淆表：全容量 36/36 检出、
  0/12 误报；≤ 10 KB 0/60 检出、60 漏报、0/12 误报。
- **一句结论：** 只有接近满容量可稳定检出；≤ 10 KB 全部漏报。
- **一句局限：** 顺序中文全容量、平滑合成载体漏报；LSB 已随机图像不可区分；真实猫图待 E 数据集。

数据来源与讲稿备注已写入 PPTX 备注页；不要在幻灯片上写密钥或把“分数”称为“含密概率”。
