## 运行

本机已经准备好桌面 mimi 的 `.venv`。双击 `运行测试.cmd` 或 `运行演示.cmd` 即可。
若把交付目录复制到其他电脑，先安装 Python，再双击 `安装依赖.cmd`，会在本目录创建独立 `.venv`。

PowerShell 命令（在本目录）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-d.txt
.\.venv\Scripts\python.exe scripts/run_d_checks.py
.\.venv\Scripts\python.exe scripts/demo_d_mimi.py
.\.venv\Scripts\python.exe scripts/build_d_materials.py
```

实测环境：Python 3.14.5；依赖版本见 `requirements.txt`、`requirements-d.txt` 和 `outputs/d_mimi/test_results.json`。
模块运行只依赖 Pillow；项目基线另依赖 qrcode；zxing-cpp 用于真实扫码，python-pptx 用于生成演示文稿。
原 mimi 的 `.deps` 中 Pillow 二进制不兼容当前解释器，测试入口先从独立环境加载依赖，不删除或更改原缓存。

## 自己验证 PNG

以下命令每次隐藏输入同一把非空完整性密钥。先对可信的基准图建立自己的记录；不要对待检攻击图重新建立基准。

```powershell
.\.venv\Scripts\python.exe d_integrity_cli.py create outputs/d_mimi/keyed/reference.png my_record.json --region 348 32 160 200 --image-id my-mimi-D
.\.venv\Scripts\python.exe d_integrity_cli.py verify outputs/d_mimi/keyed/reference.png my_record.json
.\.venv\Scripts\python.exe d_integrity_cli.py verify outputs/d_mimi/keyed/inside_high_bit.png my_record.json
.\.venv\Scripts\python.exe d_integrity_cli.py verify outputs/d_mimi/keyed/outside_region.png my_record.json
```

后三项应依次为 passed / failed / passed。省略 create 的 `--region` 则认证整图。
CLI拒绝覆盖已有记录。校验退出码：passed=0，failed=1，unknown=2。支持 `--key-env`，不支持把密钥直接放在命令行参数里。
实验随机密钥仅保存在进程中，附带元数据是格式与结果展示；重跑时生成新密钥，不保证标签、置乱位置和耗时字节级相同。
